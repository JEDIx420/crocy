## Strict Development Protocol
Per directive rules:
1. Work is executed strictly one phase at a time.
2. After completing each phase, work is pushed, evidence captured, documentation updated, and development **stops completely** for user testing and explicit approval.
3. No subsequent phase may be started until the current phase is approved.
